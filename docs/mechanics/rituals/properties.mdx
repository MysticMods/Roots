## Ritual Properties

Ritual properties are defined by NeoForge data maps. You can view the default ritual properties [in the Roots 4 source code](https://github.com/MysticMods/Roots/blob/1.21.1/src/generated/resources/data/roots/data_maps/roots/rituals/ritual_property_data.json). To modify these properties, please check out the "Developer Information" section.
